# UX v2 Implementation Plan — Search, Detail, Filter, Help, Pause, Levels, Reconnect, JSON Highlighting (UI + TUI)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the Leptos browser UI (`ui/sift-ui/`) and the Ratatui TUI (`crates/sift-cli/src/tui/`) to feature parity on eight new UX capabilities, shipped together in lockstep.

**Architecture:** Both clients follow the same shape: a pure state/model layer that's unit-tested, a pure rendering layer, and an I/O layer for WebSocket + HTTP. Features land as paired UI/TUI task pairs where possible so the two clients never drift. The UI adds `leptos_router` for tab navigation and adopts `gloo-net` for HTTP / `gloo-timers` for reconnect backoff. The TUI grows a `Mode` enum and per-mode input dispatch. Both reuse `sift_api::SearchQuery`/`SearchResponse` (existing) and `sift_api::TailFrame` (existing — the UI still mirrors the shape locally because wasm32 doesn't share the workspace).

**Tech Stack:** Rust 2021 · Leptos 0.6 (CSR) + leptos_router 0.6 + gloo-net 0.6 + gloo-timers 0.3 (UI) · Ratatui 0.29 + crossterm 0.28 + tokio 1.40 + reqwest 0.12 (TUI) · serde_json 1 · chrono 0.4.

**Spec:** `docs/superpowers/specs/2026-04-23-ux-v2-design.md` (commit 306d608).

## Ground rules for every task

- **One concern per commit.** Each task ends with a single commit.
- **TDD where practical.** Pure-state and pure-view tasks start with a failing test. I/O tasks (WebSocket, HTTP) rely on smoke testing per the spec.
- **Always run `cargo fmt --all`** after editing Rust files. Fold any fmt-only hunks into the same commit.
- **Build check before committing.** For UI tasks: `cd ui/sift-ui && trunk build` (or `cargo check --target wasm32-unknown-unknown`). For TUI tasks: `cargo check -p sift-cli && cargo test -p sift-cli`.

```rust
//! Live-tail route. Owns the record list signal and renders rows.

use leptos::*;
use serde::Deserialize;
use wasm_bindgen::closure::Closure;
use wasm_bindgen::JsCast;
use web_sys::{CloseEvent, Event, MessageEvent, WebSocket};

#[derive(Debug, Clone, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
enum TailFrame {
    Record(TailRecord),
    Heartbeat,
    Error { message: String },
    #[serde(other)]
    Unknown,
}

#[derive(Debug, Clone, Deserialize)]
pub struct TailRecord {
    pub timestamp: String,
    pub host: String,
    pub app: String,
    #[serde(default)]
    pub level: String,
    pub body: String,
}

#[derive(Clone, Copy, PartialEq, Eq)]
pub enum Status {
    Connecting,
    Open,
    Closed,
}

impl Status {
    pub fn label(self) -> &'static str {
        match self {
            Self::Connecting => "connecting",
            Self::Open => "connected",
            Self::Closed => "disconnected",
        }
    }
    pub fn css(self) -> &'static str {
        match self {
            Self::Open => "status ok",
            Self::Closed => "status err",
            Self::Connecting => "status",
        }
    }
}

#[component]
pub fn Tail() -> impl IntoView {
    let records = create_rw_signal(Vec::<TailRecord>::new());
    let status = create_rw_signal(Status::Connecting);
    connect(records, status);

    view! {
        <div class="tail-status-line">
            <span class=move || status.get().css()>
                { move || status.get().label() }
            </span>
        </div>
        { move || {
            let rs = records.get();
            if rs.is_empty() {
                view! { <div class="empty">"waiting for records…"</div> }.into_view()
            } else {
                view! {
                    <For
                        each={move || records.get().into_iter().enumerate().collect::<Vec<_>>()}
                        key={|(i, _)| *i}
                        children={move |(_, r)| view! {
                            <div class="row">
                                <span class="ts">{r.timestamp.clone()}</span>
                                <span class="host">{r.host.clone()}</span>
                                <span class="app">{r.app.clone()}</span>
                                <span class=format!("lvl {}", r.level)>{r.level.clone()}</span>
                                <span class="body">{r.body.clone()}</span>
                            </div>
                        }}
                    />
                }.into_view()
            }
        }}
    }
}

fn connect(records: RwSignal<Vec<TailRecord>>, status: RwSignal<Status>) {
    let location = web_sys::window().and_then(|w| w.location().host().ok()).unwrap_or_default();
    let proto = web_sys::window()
        .and_then(|w| w.location().protocol().ok())
        .unwrap_or_else(|| "http:".to_string());
    let ws_scheme = if proto == "https:" { "wss" } else { "ws" };
    let url = format!("{ws_scheme}://{location}/v1/tail");

    let ws = match WebSocket::new(&url) {
        Ok(ws) => ws,
        Err(_) => { status.set(Status::Closed); return; }
    };

    let on_open_status = status;
    let on_open = Closure::<dyn FnMut(Event)>::new(move |_| on_open_status.set(Status::Open));
    ws.set_onopen(Some(on_open.as_ref().unchecked_ref()));
    on_open.forget();

    let records_for_msg = records;
    let on_message = Closure::<dyn FnMut(MessageEvent)>::new(move |evt: MessageEvent| {
        let Some(text) = evt.data().as_string() else { return };
        match serde_json::from_str::<TailFrame>(&text) {
            Ok(TailFrame::Record(r)) => records_for_msg.update(|v| {
                v.push(r);
                if v.len() > 500 { v.drain(..v.len() - 500); }
            }),
            Ok(TailFrame::Heartbeat) => {}
            Ok(TailFrame::Error { message }) => log::warn!("server error frame: {message}"),
            Ok(TailFrame::Unknown) => {}
            Err(e) => log::error!("bad frame: {e}"),
        }
    });
    ws.set_onmessage(Some(on_message.as_ref().unchecked_ref()));
    on_message.forget();

    let on_close_status = status;
    let on_close = Closure::<dyn FnMut(CloseEvent)>::new(move |_| on_close_status.set(Status::Closed));
    ws.set_onclose(Some(on_close.as_ref().unchecked_ref()));
    on_close.forget();

    let on_error_status = status;
    let on_error = Closure::<dyn FnMut(Event)>::new(move |_| on_error_status.set(Status::Closed));
    ws.set_onerror(Some(on_error.as_ref().unchecked_ref()));
    on_error.forget();
}
```

```rust
//! Keyboard dispatch. Pure function: `AppState` in, mutations out. The
//! `mod.rs` caller converts crossterm events into `KeyEvent`s and drops them
//! here. Keep this file free of I/O — unit tests drive it directly.

use crossterm::event::{KeyCode, KeyEvent, KeyModifiers};

use super::state::{AppState, Focus, Mode};

pub fn dispatch(state: &mut AppState, key: KeyEvent) {
    if key.modifiers.contains(KeyModifiers::CONTROL) && matches!(key.code, KeyCode::Char('c')) {
        state.quit();
        return;
    }

    match (state.mode, state.focus) {
        (Mode::Tail, Focus::List) => tail_list(state, key),
        (Mode::Tail, Focus::Filter) => tail_filter(state, key),
        (Mode::Search, _) => search(state, key),
    }
}

fn tail_list(state: &mut AppState, key: KeyEvent) {
    match key.code {
        KeyCode::Char('q') => state.quit(),
        KeyCode::Char('/') => state.focus_filter(),
        KeyCode::Char('s') => state.set_mode(Mode::Search),
        KeyCode::Char('t') => state.set_mode(Mode::Tail),
        KeyCode::Up => state.scroll_up(1),
        KeyCode::Down => state.scroll_down(1),
        KeyCode::PageUp => state.scroll_up(10),
        KeyCode::PageDown => state.scroll_down(10),
        KeyCode::Home => state.scroll_up(usize::MAX / 2),
        KeyCode::End => state.follow(),
        _ => {}
    }
}

fn tail_filter(state: &mut AppState, key: KeyEvent) {
    match key.code {
        KeyCode::Esc | KeyCode::Enter => state.unfocus_filter(),
        KeyCode::Backspace => {
            let mut s = state.filter.clone();
            s.pop();
            state.set_filter(s);
        }
        KeyCode::Char(c) => {
            let mut s = state.filter.clone();
            s.push(c);
            state.set_filter(s);
        }
        _ => {}
    }
}
```

```rust
    let recs = state.filtered();

        } else {

pub(super) fn visible_range(total: usize, visible: usize, scroll: ScrollMode) -> (usize, usize) {
    if total == 0 || visible == 0 {
        return (0, 0);
    }
    let v = visible.min(total);
    match scroll {
        ScrollMode::Follow => (total - v, total),
        ScrollMode::Locked { offset } => {
            let start = offset.min(total.saturating_sub(1));
            let end = (start + v).min(total);
            (start, end)
        }
    }
}

fn row(r: &Record) -> ListItem<'_> {

        Span::raw(" "),
        Span::styled(format!("{:<8}", r.app), Style::default().fg(Color::Gray)),
        Span::raw(" "),
        level_s,
        Span::raw(" "),
        Span::raw(r.body.clone()),
    ]);
    ListItem::new(line)
}

}
```

```rust
//! From/to datetime-local inputs plus three quick-range buttons.
//!
//! The component is controlled: the parent holds the two RwSignals and
//! receives a callback when the user clicks a quick-range button. The parent
//! decides what to do with the populated values (e.g. submit the search).
//!
//! Time semantics: picker values are UTC. Users who want local time can
//! type seconds and a timezone into the input directly; the picker's native
//! behaviour is local but we convert to UTC RFC3339 at submit time.

use leptos::*;

#[derive(Clone, Copy, Debug, PartialEq)]
pub enum QuickRange {
    OneHour,
    OneDay,
    SevenDays,
}

impl QuickRange {
    pub fn label(self) -> &'static str {
        match self {
            Self::OneHour => "Last 1h",
            Self::OneDay => "Last 24h",
            Self::SevenDays => "Last 7d",
        }
    }
    /// Number of seconds back from `now` the range starts.
    pub fn seconds(self) -> i64 {
        match self {
            Self::OneHour => 3_600,
            Self::OneDay => 86_400,
            Self::SevenDays => 7 * 86_400,
        }
    }
}

#[component]
pub fn TimeRange(

        to.set(hi);

    };

/// Compute (from, to) strings for the datetime-local input, UTC.
/// Return format: "YYYY-MM-DDTHH:MM:SS" (no timezone marker — picker doesn't accept Z).
pub(crate) fn compute_range(r: QuickRange) -> (String, String) {
    let now_ms = js_sys::Date::now() as i64; // epoch ms, UTC
    let lo_ms = now_ms - r.seconds() * 1000;
    (format_utc(lo_ms), format_utc(now_ms))
}

fn format_utc(ms: i64) -> String {
    let d = js_sys::Date::new(&wasm_bindgen::JsValue::from_f64(ms as f64));
    format!(
        "{:04}-{:02}-{:02}T{:02}:{:02}:{:02}",
        d.get_utc_full_year(),
        d.get_utc_month() + 1,
        d.get_utc_date(),
        d.get_utc_hours(),
        d.get_utc_minutes(),
        d.get_utc_seconds(),
    )
}
```

```rust
/// Convert a datetime-local string ("2026-04-23T12:00" or "2026-04-23T12:00:00")
/// into RFC3339 UTC ("2026-04-23T12:00:00Z"). Returns None for empty input.
fn to_rfc3339(v: &str) -> Option<String> {
    if v.is_empty() {
        return None;
    }
    // datetime-local gives us either minute or second precision; we append
    // :00 if needed and always append Z.
    let core = if v.len() == 16 { format!("{v}:00") } else { v.to_string() };
    Some(format!("{core}Z"))
}

async fn run_search(req: SearchQuery) -> Result<SearchResponse, String> {
    let mut url = "/v1/search".to_string();
    let mut first = true;
    let mut push = |k: &str, v: &str| {
        let sep = if first { '?' } else { '&' };
        first = false;
        url.push(sep);
        url.push_str(&format!(
            "{}={}",
            k,
            js_sys::encode_uri_component(v)
        ));
    };
    push("q", &req.q);
    push("limit", &req.limit.to_string());
    if let Some(f) = &req.from { push("from", f); }
    if let Some(t) = &req.to { push("to", t); }

    gloo_net::http::Request::get(&url)
        .send()
        .await
        .map_err(|e| e.to_string())?
        .json::<SearchResponse>()
        .await
        .map_err(|e| e.to_string())
}
```

```rust
fn search(state: &mut AppState, key: KeyEvent) {
    use super::state::{SearchFocus, SearchStatus};

    match key.code {
        KeyCode::Esc => state.set_mode(Mode::Tail),
        KeyCode::Char('c') if key.modifiers.contains(KeyModifiers::CONTROL) => state.quit(),
        KeyCode::Tab => state.cycle_search_focus(true),
        KeyCode::BackTab => state.cycle_search_focus(false),

        // Quick ranges: only respond when focus is NOT an input (i.e. Query focus
        // with empty query would eat the char; we only trigger when q/from/to
        // inputs are unfocused via Esc). Simpler: trigger on Alt+1/2/3.
        KeyCode::Char('1') if key.modifiers.contains(KeyModifiers::ALT) => {
            apply_quick_range(state, 3_600);
        }
        KeyCode::Char('2') if key.modifiers.contains(KeyModifiers::ALT) => {
            apply_quick_range(state, 86_400);
        }
        KeyCode::Char('3') if key.modifiers.contains(KeyModifiers::ALT) => {
            apply_quick_range(state, 7 * 86_400);
        }

        KeyCode::Up => state.search_cursor_up(),
        KeyCode::Down => state.search_cursor_down(),

        KeyCode::Enter => {
            // Enter on the Query field submits. Enter on From/To cycles focus.
            match state.search_focus {
                SearchFocus::Query => state.search_status = SearchStatus::Running,
                _ => state.cycle_search_focus(true),
            }
        }

        KeyCode::Backspace => pop_focused(state),
        KeyCode::Char(c) => push_focused(state, c),

        _ => {}
    }
}

fn push_focused(state: &mut AppState, c: char) {
    use super::state::SearchFocus;
    match state.search_focus {
        SearchFocus::Query => state.search_q.push(c),
        SearchFocus::From => state.search_from.push(c),
        SearchFocus::To => state.search_to.push(c),
    }
}

fn pop_focused(state: &mut AppState) {
    use super::state::SearchFocus;
    match state.search_focus {
        SearchFocus::Query => { state.search_q.pop(); }
        SearchFocus::From => { state.search_from.pop(); }
        SearchFocus::To => { state.search_to.pop(); }
    }
}

fn apply_quick_range(state: &mut super::state::AppState, seconds_back: i64) {
    use chrono::Utc;
    let now = Utc::now();
    let lo = now - chrono::Duration::seconds(seconds_back);
    state.search_from = lo.to_rfc3339_opts(chrono::SecondsFormat::Secs, true);
    state.search_to = now.to_rfc3339_opts(chrono::SecondsFormat::Secs, true);
    state.search_status = super::state::SearchStatus::Running;
}
```

```rust
async fn run_search(base: &str, q: &str, from: &str, to: &str) -> SearchOutcome {
    let started = std::time::Instant::now();
    let url = format!("{}/v1/search", base.trim_end_matches('/'));

            },
            Err(e) => SearchOutcome::Err(e.to_string()),
        },
        Err(e) => SearchOutcome::Err(e.to_string()),
```

Create `ui/sift-ui/src/components/json_highlight.rs`:

```rust
//! Pure tokenizer for pretty-printed JSON. Produces `(TokenKind, String)` pairs
//! that the Leptos view renders as <span class="…">. No allocations that aren't
//! forced by the borrow; strings are owned because the tokenizer is used once
//! per detail-panel render.

use leptos::*;
use serde_json::Value;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum TokenKind {
    Key,
    String,
    Number,
    Bool,
    Null,
    Punct,
    Whitespace,
}

impl TokenKind {
    pub fn css_class(self) -> &'static str {
        match self {
            Self::Key => "json-key",
            Self::String => "json-string",
            Self::Number | Self::Bool | Self::Null => "json-scalar",
            Self::Punct => "json-punct",
            Self::Whitespace => "json-ws",
        }
    }
}

pub fn tokenize(v: &Value) -> Vec<(TokenKind, String)> {
    let mut out = Vec::new();
    walk(v, 0, &mut out);
    out
}

fn walk(v: &Value, indent: usize, out: &mut Vec<(TokenKind, String)>) {
    match v {
        Value::Null => out.push((TokenKind::Null, "null".into())),
        Value::Bool(b) => out.push((TokenKind::Bool, b.to_string())),
        Value::Number(n) => out.push((TokenKind::Number, n.to_string())),
        Value::String(s) => out.push((TokenKind::String, format!("\"{}\"", escape(s)))),
        Value::Array(arr) => walk_array(arr, indent, out),
        Value::Object(map) => walk_object(map, indent, out),
    }
}

fn walk_array(arr: &[Value], indent: usize, out: &mut Vec<(TokenKind, String)>) {
    if arr.is_empty() {
        out.push((TokenKind::Punct, "[]".into()));
        return;
    }
    out.push((TokenKind::Punct, "[".into()));
    out.push((TokenKind::Whitespace, "\n".into()));
    let inner = indent + 2;
    for (i, v) in arr.iter().enumerate() {
        out.push((TokenKind::Whitespace, " ".repeat(inner)));
        walk(v, inner, out);
        if i + 1 < arr.len() {
            out.push((TokenKind::Punct, ",".into()));
        }
        out.push((TokenKind::Whitespace, "\n".into()));
    }
    out.push((TokenKind::Whitespace, " ".repeat(indent)));
    out.push((TokenKind::Punct, "]".into()));
}

fn walk_object(
    map: &serde_json::Map<String, Value>,
    indent: usize,
    out: &mut Vec<(TokenKind, String)>,
) {
    if map.is_empty() {
        out.push((TokenKind::Punct, "{}".into()));
        return;
    }
    out.push((TokenKind::Punct, "{".into()));
    out.push((TokenKind::Whitespace, "\n".into()));
    let inner = indent + 2;
    let last = map.len() - 1;
    for (i, (k, v)) in map.iter().enumerate() {
        out.push((TokenKind::Whitespace, " ".repeat(inner)));
        out.push((TokenKind::Key, format!("\"{}\"", escape(k))));
        out.push((TokenKind::Punct, ": ".into()));
        walk(v, inner, out);
        if i != last {
            out.push((TokenKind::Punct, ",".into()));
        }
        out.push((TokenKind::Whitespace, "\n".into()));
    }
    out.push((TokenKind::Whitespace, " ".repeat(indent)));
    out.push((TokenKind::Punct, "}".into()));
}

fn escape(s: &str) -> String {
    let mut o = String::with_capacity(s.len());
    for c in s.chars() {
```

```rust
//! Pretty-print + colorize a `serde_json::Value` into `Vec<Line<'static>>`
//! for Ratatui. Pure function, no I/O.

use ratatui::style::{Color, Style};
use ratatui::text::{Line, Span};
use serde_json::Value;

pub fn highlight(v: &Value) -> Vec<Line<'static>> {
    let mut lines: Vec<Line<'static>> = Vec::new();
    let mut current: Vec<Span<'static>> = Vec::new();
    walk(v, 0, &mut lines, &mut current);
    if !current.is_empty() {
        lines.push(Line::from(std::mem::take(&mut current)));
    }
    lines
}

fn walk(
    v: &Value,
    indent: usize,
    lines: &mut Vec<Line<'static>>,
    current: &mut Vec<Span<'static>>,
) {
    match v {
        Value::Null => current.push(scalar("null")),
        Value::Bool(b) => current.push(scalar(if *b { "true" } else { "false" }.to_string())),
        Value::Number(n) => current.push(scalar(n.to_string())),
        Value::String(s) => current.push(string_span(format!("\"{}\"", escape(s)))),
        Value::Array(arr) => walk_array(arr, indent, lines, current),
        Value::Object(map) => walk_object(map, indent, lines, current),
    }
}

fn walk_array(
    arr: &[Value],
    indent: usize,
    lines: &mut Vec<Line<'static>>,
    current: &mut Vec<Span<'static>>,
) {
    if arr.is_empty() {
        current.push(punct("[]"));
        return;
    }
    current.push(punct("["));
    flush(lines, current);

    let inner = indent + 2;
    let last = arr.len() - 1;
    for (i, v) in arr.iter().enumerate() {
        current.push(Span::raw(" ".repeat(inner)));
        walk(v, inner, lines, current);
        if i != last {
            current.push(punct(","));
        }
        flush(lines, current);
    }
    current.push(Span::raw(" ".repeat(indent)));
    current.push(punct("]"));
}

fn walk_object(
    map: &serde_json::Map<String, Value>,
    indent: usize,
    lines: &mut Vec<Line<'static>>,
    current: &mut Vec<Span<'static>>,
) {
    if map.is_empty() {
        current.push(punct("{}"));
        return;
    }
    current.push(punct("{"));
    flush(lines, current);

    let inner = indent + 2;
    let last = map.len() - 1;
    for (i, (k, v)) in map.iter().enumerate() {
        current.push(Span::raw(" ".repeat(inner)));
        current.push(key_span(format!("\"{}\"", escape(k))));
        current.push(punct(": "));
        walk(v, inner, lines, current);
        if i != last {
            current.push(punct(","));
        }
        flush(lines, current);
    }
    current.push(Span::raw(" ".repeat(indent)));
    current.push(punct("}"));
}

fn flush(lines: &mut Vec<Line<'static>>, current: &mut Vec<Span<'static>>) {
    lines.push(Line::from(std::mem::take(current)));
}

fn key_span(s: String) -> Span<'static> {
    Span::styled(s, Style::default().fg(Color::Cyan))
}

fn string_span(s: String) -> Span<'static> {
    Span::styled(s, Style::default().fg(Color::Green))
}

fn scalar(s: impl Into<String>) -> Span<'static> {
    Span::styled(s.into(), Style::default().fg(Color::Yellow))
}

fn punct(s: impl Into<String>) -> Span<'static> {
    Span::styled(s.into(), Style::default().fg(Color::DarkGray))
}

fn escape(s: &str) -> String {
    let mut o = String::with_capacity(s.len());
    for c in s.chars() {
        match c {
            '"' => o.push_str("\\\""),
            '\\' => o.push_str("\\\\"),
            '\n' => o.push_str("\\n"),
            '\r' => o.push_str("\\r"),
            '\t' => o.push_str("\\t"),
            c if (c as u32) < 0x20 => o.push_str(&format!("\\u{:04x}", c as u32)),
            c => o.push(c),
        }
    }
    o
}
```

```rust
//! Centered 80%×80% popup over the main view. Shows full record details with
//! JSON-highlighted fields. Overlays whatever's beneath using Clear.

use ratatui::layout::{Constraint, Layout, Rect};
use ratatui::style::{Color, Modifier, Style};
use ratatui::text::{Line, Span};
use ratatui::widgets::{Block, Borders, Clear, Paragraph, Wrap};
use ratatui::Frame;
use sift_core::Record;

use super::jsonfmt;

pub fn draw_detail(f: &mut Frame, r: &Record) {
    let area = centered_rect(80, 80, f.area());
    f.render_widget(Clear, area);

    let block = Block::default()
        .title(" record · Esc to close ")
        .borders(Borders::ALL)
        .border_style(Style::default().fg(Color::Cyan));
    let inner = block.inner(area);
    f.render_widget(block, area);

    let [header, body_area, labels_area, fields_area, raw_area] = Layout::vertical([
        Constraint::Length(2),
        Constraint::Length(4),
        Constraint::Length(6),
        Constraint::Min(3),
        Constraint::Length(3),
    ])
    .areas(inner);

    render_header(f, header, r);
    render_body(f, body_area, r);
    render_labels(f, labels_area, r);
    render_fields(f, fields_area, r);
    render_raw(f, raw_area, r);
}

fn render_header(f: &mut Frame, area: Rect, r: &Record) {
    let ts = r.timestamp.to_rfc3339();
    let line = Line::from(vec![
        Span::styled(ts, Style::default().fg(Color::DarkGray)),
        Span::raw("  "),
        Span::styled(r.host.clone(), Style::default().fg(Color::Gray)),
        Span::raw(" · "),
        Span::styled(r.app.clone(), Style::default().fg(Color::Gray)),
        Span::raw(" · "),
        Span::styled(r.stream_id.clone(), Style::default().fg(Color::Gray)),
        Span::raw(" · "),
        Span::styled(format!("{:?}", r.level), Style::default().fg(Color::Yellow)),
    ]);
    f.render_widget(Paragraph::new(line).wrap(Wrap { trim: false }), area);
}

fn render_body(f: &mut Frame, area: Rect, r: &Record) {
    let block = Block::default().title(" body ").borders(Borders::TOP);
    let inner = block.inner(area);
    f.render_widget(block, area);
    f.render_widget(Paragraph::new(r.body.clone()).wrap(Wrap { trim: false }), inner);
}

fn render_labels(f: &mut Frame, area: Rect, r: &Record) {
    let block = Block::default().title(" labels ").borders(Borders::TOP);
    let inner = block.inner(area);
    f.render_widget(block, area);

    if r.labels.is_empty() {
        f.render_widget(
            Paragraph::new("(none)").style(Style::default().fg(Color::DarkGray)),
            inner,
        );
        return;
    }

    let lines: Vec<Line<'static>> = r
        .labels
        .iter()
        .map(|(k, v)| Line::from(vec![
            Span::styled(k.clone(), Style::default().fg(Color::DarkGray).add_modifier(Modifier::BOLD)),
            Span::raw("  "),
            Span::raw(v.clone()),
        ]))
        .collect();
    f.render_widget(Paragraph::new(lines), inner);
}

fn render_fields(f: &mut Frame, area: Rect, r: &Record) {
    let block = Block::default().title(" fields ").borders(Borders::TOP);
    let inner = block.inner(area);
    f.render_widget(block, area);

    if r.fields.is_empty() {
        f.render_widget(
            Paragraph::new("(none)").style(Style::default().fg(Color::DarkGray)),
            inner,
        );
        return;
    }
    let value = serde_json::to_value(&r.fields).unwrap_or(serde_json::Value::Null);
    let lines = jsonfmt::highlight(&value);
    f.render_widget(Paragraph::new(lines).wrap(Wrap { trim: false }), inner);
}

fn render_raw(f: &mut Frame, area: Rect, r: &Record) {
    let block = Block::default().title(" raw ").borders(Borders::TOP);
    let inner = block.inner(area);
    f.render_widget(block, area);
    let text = r.raw.clone().unwrap_or_else(|| "(none)".into());
    f.render_widget(Paragraph::new(text).wrap(Wrap { trim: false }), inner);
}

/// Centered rect covering `percent_x`/`percent_y` of the area.
fn centered_rect(percent_x: u16, percent_y: u16, area: Rect) -> Rect {
    let [_, v, _] = Layout::vertical([
        Constraint::Percentage((100 - percent_y) / 2),
        Constraint::Percentage(percent_y),
        Constraint::Percentage((100 - percent_y) / 2),
    ])
    .areas(area);

    let [_, h, _] = Layout::horizontal([
        Constraint::Percentage((100 - percent_x) / 2),
        Constraint::Percentage(percent_x),
        Constraint::Percentage((100 - percent_x) / 2),
    ])
    .areas(v);

    h
}
```

```rust
//! Level visibility pill row. Lives in the top shell so it applies to both
//! tail and search result lists.

use leptos::*;

#[derive(Clone, Copy, Debug)]
pub struct LevelSet {
    pub trace: bool,
    pub debug: bool,
    pub info: bool,
    pub warn: bool,
    pub error: bool,
    pub fatal: bool,
}

impl Default for LevelSet {
    fn default() -> Self {
        // Visible by default: info, warn, error, fatal.
        Self { trace: false, debug: false, info: true, warn: true, error: true, fatal: true }
    }
}

impl LevelSet {
    pub fn allows(&self, lvl: &str) -> bool {
        match lvl {
            "trace" => self.trace,
            "debug" => self.debug,
            "info" => self.info,
            "warn" => self.warn,
            "error" => self.error,
            "fatal" => self.fatal,
            _ => true, // Unknown levels stay visible.
        }
    }
}

#[component]
pub fn LevelToggle(set: RwSignal<LevelSet>) -> impl IntoView {
    let show_more = create_rw_signal(false);

    let pill = move |label: &'static str, get: Box<dyn Fn(LevelSet) -> bool>, toggle: Box<dyn Fn(&mut LevelSet)>| {
        let get = std::rc::Rc::new(get);
        let toggle = std::rc::Rc::new(toggle);
        let class = {
            let get = get.clone();
            move || if get(set.get()) { "level-pill on" } else { "level-pill off" }
        };
        let onclick = {
            let toggle = toggle.clone();
            move |_| set.update(|s| toggle(s))
        };
        view! {
            <button type="button" class=class on:click=onclick>{label}</button>
        }
    };

    view! {
        <div class="level-toggle">
            { pill("info",  Box::new(|s: LevelSet| s.info),  Box::new(|s: &mut LevelSet| s.info  = !s.info)) }
            { pill("warn",  Box::new(|s: LevelSet| s.warn),  Box::new(|s: &mut LevelSet| s.warn  = !s.warn)) }
            { pill("error", Box::new(|s: LevelSet| s.error), Box::new(|s: &mut LevelSet| s.error = !s.error)) }
            { pill("fatal", Box::new(|s: LevelSet| s.fatal), Box::new(|s: &mut LevelSet| s.fatal = !s.fatal)) }
            <button type="button" class="level-more" on:click=move |_| show_more.update(|v| *v = !*v)>
                { move || if show_more.get() { "less" } else { "more…" } }
            </button>
            { move || if show_more.get() {
                view! {
                    <>
                    { pill("debug", Box::new(|s: LevelSet| s.debug), Box::new(|s: &mut LevelSet| s.debug = !s.debug)) }
                    { pill("trace", Box::new(|s: LevelSet| s.trace), Box::new(|s: &mut LevelSet| s.trace = !s.trace)) }
                    </>
                }.into_view()
            } else {
                view! { <></> }.into_view()
            }}
        </div>
    }
}
```

```rust
pub fn connect(
    on_record: impl Fn(RowRecord) + 'static,
    status: RwSignal<Status>,
) {
    let location = web_sys::window().and_then(|w| w.location().host().ok()).unwrap_or_default();
    let proto = web_sys::window()
        .and_then(|w| w.location().protocol().ok())
        .unwrap_or_else(|| "http:".to_string());
    let ws_scheme = if proto == "https:" { "wss" } else { "ws" };
    let url = format!("{ws_scheme}://{location}/v1/tail");

    let ws = match WebSocket::new(&url) {
        Ok(ws) => ws,
        Err(_) => { status.set(Status::Closed); return; }
    };

    let on_open_status = status;
    let on_open = Closure::<dyn FnMut(Event)>::new(move |_| on_open_status.set(Status::Open));
    ws.set_onopen(Some(on_open.as_ref().unchecked_ref()));
    on_open.forget();

    let on_message = Closure::<dyn FnMut(MessageEvent)>::new(move |evt: MessageEvent| {
        let Some(text) = evt.data().as_string() else { return };
        match serde_json::from_str::<TailFrame>(&text) {
            Ok(TailFrame::Record(r)) => on_record(r),
            Ok(TailFrame::Heartbeat) => {}
            Ok(TailFrame::Error { message }) => log::warn!("server error frame: {message}"),
            Ok(TailFrame::Unknown) => {}
            Err(e) => log::error!("bad frame: {e}"),
        }
    });
    ws.set_onmessage(Some(on_message.as_ref().unchecked_ref()));
    on_message.forget();

    let on_close_status = status;
    let on_close = Closure::<dyn FnMut(CloseEvent)>::new(move |_| on_close_status.set(Status::Closed));
    ws.set_onclose(Some(on_close.as_ref().unchecked_ref()));
    on_close.forget();

    let on_error_status = status;
    let on_error = Closure::<dyn FnMut(Event)>::new(move |_| on_error_status.set(Status::Closed));
    ws.set_onerror(Some(on_error.as_ref().unchecked_ref()));
    on_error.forget();
```

```rust
use leptos::*;

use crate::app::{LevelCtx, OpenDetail};
use crate::components::filter_bar::FilterBar;
use crate::components::pause_button::PauseButton;
use crate::components::record_row::{RecordRow, RowRecord};
use crate::ws::{connect, Status};

const TAIL_CAP: usize = 500;

#[component]
pub fn Tail() -> impl IntoView {
    let records = create_rw_signal(Vec::<RowRecord>::new());
    let pending = create_rw_signal(Vec::<RowRecord>::new());
    let pending_count = create_rw_signal(0usize);
    let paused = create_rw_signal(false);
    let status = create_rw_signal(Status::Connecting);
    let filter = create_rw_signal(String::new());

    // Route new records: when paused, queue in pending; when live, append to main list.
    let on_record = move |r: RowRecord| {
        if paused.get_untracked() {
            pending.update(|v| {
                v.push(r);
                if v.len() > TAIL_CAP { v.drain(..v.len() - TAIL_CAP); }
            });
            pending_count.set(pending.with(|v| v.len()));
        } else {
            records.update(|v| {
                v.push(r);
                if v.len() > TAIL_CAP { v.drain(..v.len() - TAIL_CAP); }
            });
        }
    };
    connect(on_record, status);

    let on_resume = Callback::new(move |_: ()| {
        let mut drained: Vec<RowRecord> = Vec::new();
        pending.update(|v| { drained = std::mem::take(v); });
        records.update(|main| {
            main.extend(drained);
            if main.len() > TAIL_CAP { let over = main.len() - TAIL_CAP; main.drain(..over); }
        });
        pending_count.set(0);
    });

    let level_ctx = use_context::<LevelCtx>().expect("LevelCtx").0;

    // Filter order: level → substring. Both produce the visible set.
    let level_filtered = move || {
        let lvl = level_ctx.get();
        records.get().into_iter().filter(|r| lvl.allows(&r.level)).collect::<Vec<_>>()
    };
    let visible = move || {
        let needle = filter.get();
        if needle.is_empty() { return level_filtered(); }
        level_filtered().into_iter().filter(|r| r.body.contains(&needle)).collect()
    };
    let matches_counter = move || {
        let needle = filter.get();
        if needle.is_empty() { return String::new(); }
        let after_level = level_filtered().len();
        let after_filter = after_level.saturating_sub(
            level_filtered().into_iter().filter(|r| !r.body.contains(&needle)).count()
        );
        // Simpler — recompute once:
        let shown = visible().len();
        let hidden = after_level.saturating_sub(shown);
        format!("{shown} matches · {hidden} filtered out")
    };

    let open = use_context::<OpenDetail>().expect("OpenDetail ctx").0;
    let on_row_click = Callback::new(move |r: RowRecord| open.set(Some(r)));

    view! {
        <div class="tail-header">
            <span class=move || status.get().css()>{ move || status.get().label() }</span>
            <FilterBar filter=filter />
            <span class="matches-counter">{ matches_counter }</span>
            <PauseButton paused=paused pending_count=pending_count on_resume=on_resume />
        </div>
        { move || {
            let vs = visible();
            if vs.is_empty() {
                view! { <div class="empty">"waiting for records…"</div> }.into_view()
            } else {
                view! {
                    <For
                        each={move || visible().into_iter().enumerate().collect::<Vec<_>>()}
                        key={|(i, _)| *i}
                        children={move |(_, r)| view! {
                            <RecordRow record=r on_click=on_row_click />
                        }}
                    />
                }.into_view()
            }
        }}
    }
}
```

```rust
use futures::channel::oneshot;
use gloo_timers::future::TimeoutFuture;
use std::cell::RefCell;
use std::rc::Rc;

/// A handle the caller can use to force an immediate reconnect.
#[derive(Clone)]
pub struct RetryHandle(Rc<RefCell<Option<oneshot::Sender<()>>>>);

impl RetryHandle {
    /// Signal the current backoff sleep to abort early. No-op if the loop
    /// isn't currently sleeping.
    pub fn retry_now(&self) {
        if let Some(tx) = self.0.borrow_mut().take() {
            let _ = tx.send(());
        }
    }
}

pub fn connect(on_record: impl Fn(RowRecord) + 'static + Clone, status: RwSignal<Status>) -> RetryHandle {
    let retry_slot: Rc<RefCell<Option<oneshot::Sender<()>>>> = Rc::new(RefCell::new(None));
    let handle = RetryHandle(retry_slot.clone());

    let status_sig = status;
    let on_rec = on_record;
    wasm_bindgen_futures::spawn_local(async move {
        let mut attempt: u32 = 0;
        loop {
            if attempt == 0 {
                status_sig.set(Status::Connecting);
            }

            let url = build_url();
            let (done_tx, done_rx) = oneshot::channel::<()>();
            match attach(&url, on_rec.clone(), status_sig, done_tx) {
                Ok(()) => {
                    // Wait for the socket to tell us it's dead.
                    let _ = done_rx.await;
                }
                Err(()) => {
                    // WebSocket::new failed outright; fall through to backoff.
                }
            }

            // Socket closed. Compute backoff and sleep (cancellable).
            attempt = attempt.saturating_add(1);
            let delay_ms = backoff_ms(attempt);
            status_sig.set(Status::Reconnecting { attempt, next_in_ms: delay_ms });

            let (cancel_tx, cancel_rx) = oneshot::channel::<()>();
            *retry_slot.borrow_mut() = Some(cancel_tx);
            futures::select! {
                _ = TimeoutFuture::new(delay_ms).fuse() => {}
                _ = cancel_rx.fuse() => {}
            };
            // Reset attempt counter on successful future connections.
            // We still keep `attempt` across the reconnect trip; reset happens
            // only after the socket flips to Open (handled in `attach`).
        }
    });

    handle
}

fn build_url() -> String {
    let location = web_sys::window().and_then(|w| w.location().host().ok()).unwrap_or_default();
    let proto = web_sys::window()
        .and_then(|w| w.location().protocol().ok())
        .unwrap_or_else(|| "http:".to_string());
    let ws_scheme = if proto == "https:" { "wss" } else { "ws" };
    format!("{ws_scheme}://{location}/v1/tail")
}

fn backoff_ms(attempt: u32) -> u32 {
    let base = 1000u32.saturating_mul(1u32 << attempt.saturating_sub(1).min(5));
    base.min(30_000)
}

/// Open a socket, wire up callbacks, and mark `done_tx` when it closes.
/// Returns Err if construction fails (browsers rarely return Err here;
/// close/error events are delivered asynchronously).
fn attach(
    url: &str,
    on_record: impl Fn(RowRecord) + 'static,
    status: RwSignal<Status>,
    done_tx: oneshot::Sender<()>,
) -> Result<(), ()> {
    let ws = WebSocket::new(url).map_err(|_| ())?;

    let done_slot: Rc<RefCell<Option<oneshot::Sender<()>>>> = Rc::new(RefCell::new(Some(done_tx)));
    let fire_done = move |slot: &Rc<RefCell<Option<oneshot::Sender<()>>>>| {
        if let Some(tx) = slot.borrow_mut().take() {
            let _ = tx.send(());
        }
    };

    let on_open = Closure::<dyn FnMut(Event)>::new(move |_| status.set(Status::Open));
    ws.set_onopen(Some(on_open.as_ref().unchecked_ref()));
    on_open.forget();

    let on_message = Closure::<dyn FnMut(MessageEvent)>::new(move |evt: MessageEvent| {
        let Some(text) = evt.data().as_string() else { return };
        match serde_json::from_str::<TailFrame>(&text) {
            Ok(TailFrame::Record(r)) => on_record(r),
            Ok(TailFrame::Heartbeat) => {}
            Ok(TailFrame::Error { message }) => log::warn!("server error frame: {message}"),
            Ok(TailFrame::Unknown) => {}
            Err(e) => log::error!("bad frame: {e}"),
        }
    });
    ws.set_onmessage(Some(on_message.as_ref().unchecked_ref()));
    on_message.forget();

    let slot_for_close = done_slot.clone();
    let fire_close = fire_done.clone();
    let on_close = Closure::<dyn FnMut(CloseEvent)>::new(move |_| fire_close(&slot_for_close));
    ws.set_onclose(Some(on_close.as_ref().unchecked_ref()));
    on_close.forget();

    let slot_for_err = done_slot.clone();
    let fire_err = fire_done.clone();
    let on_error = Closure::<dyn FnMut(Event)>::new(move |_| fire_err(&slot_for_err));
    ws.set_onerror(Some(on_error.as_ref().unchecked_ref()));
    on_error.forget();

    Ok(())
}
```

Add `use futures::FutureExt;` at the top of `ws.rs` so `.fuse()` resolves.

```rust
    });
```

```rust
//! WebSocket tail task for the TUI with exponential-backoff auto-reconnect.
//! Forwards `WsEvent`s into an `mpsc::Sender` and listens for retry nudges
//! on a second channel so the user can force an immediate reconnect.

use std::time::Duration;

use futures_util::StreamExt;
use sift_api::TailFrame;
use tokio::sync::{mpsc, watch};
use tokio::time::timeout;
use tokio_tungstenite::connect_async;
use tokio_tungstenite::tungstenite::Message;

use super::state::{Status, WsEvent};

/// Retry signal. `run` owns the receiver; `mod.rs` keeps the sender and
/// pings it when the user presses `r`.
pub type RetrySender = mpsc::Sender<()>;

/// Run the connect/retry loop indefinitely. Exits only when `tx` is dropped.
pub async fn run(ws_url: String, tx: mpsc::Sender<WsEvent>, mut retry_rx: mpsc::Receiver<()>) {
    let mut attempt: u32 = 0;

    loop {
        if attempt == 0 {
            let _ = tx.send(WsEvent::Status(Status::Connecting)).await;
        }

        match connect_async(&ws_url).await {
            Ok((mut ws, _)) => {
                // Successful connect — reset the attempt counter.
                attempt = 0;
                let _ = tx.send(WsEvent::Status(Status::Connected)).await;

                // Forward frames until the socket closes or errors.
                while let Some(msg) = ws.next().await {
                    let Ok(msg) = msg else { break };
                    let text = match msg {
                        Message::Text(t) => t,
                        Message::Close(_) => break,
                        Message::Binary(_) | Message::Ping(_) | Message::Pong(_) | Message::Frame(_) => continue,
                    };
                    let Ok(frame) = serde_json::from_str::<TailFrame>(&text) else { continue };
                    if let TailFrame::Error { ref message } = frame {
                        tracing::warn!(%message, "server reported tail error");
                    }
                    if tx.send(WsEvent::Frame(frame)).await.is_err() {
                        return; // UI dropped; stop cleanly.
                    }
                }
            }
            Err(e) => {
                tracing::warn!(error = %e, "websocket connect failed");
            }
        }

        // Socket is dead. Compute backoff and sleep, but allow retry nudges.
        attempt = attempt.saturating_add(1);
        let delay_ms = backoff_ms(attempt);
        if tx
            .send(WsEvent::Status(Status::Reconnecting { attempt, next_in_ms: delay_ms }))
            .await
            .is_err()
        {
            return;
        }

        // Drain anything already queued on retry_rx so we don't fire twice.
        while retry_rx.try_recv().is_ok() {}

        // Wait either for the timeout or for a retry nudge.
        let _ = timeout(Duration::from_millis(delay_ms as u64), retry_rx.recv()).await;
    }
}

fn backoff_ms(attempt: u32) -> u32 {
    let shift = attempt.saturating_sub(1).min(5);
    let base = 1000u32.saturating_mul(1u32 << shift);
    base.min(30_000)
}

        .replace("http://", "ws://")
        .replace("https://", "wss://");

}
```
