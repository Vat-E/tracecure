# Sift TUI (`sift tui`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `sift tui` subcommand to the existing CLI that live-tails records in a Ratatui-based terminal UI with client-side substring filter and scrolling.

**Architecture:** A new `tui` module inside `sift-cli`. `crossterm` owns the terminal (raw mode + alternate screen) and `ratatui` 0.29 renders. A tokio task runs the WebSocket tail and forwards events (`Status` transitions and `Frame` payloads) into an `mpsc` channel. The main loop `select!`s between keyboard events and WebSocket events, updates a pure `AppState`, and redraws each frame. Pure state transitions are unit-tested; terminal lifecycle is smoke-tested manually.

**Tech Stack:** `ratatui = "0.29"`, `crossterm = "0.28"` (with `event-stream` feature). Existing deps reused: `tokio` (full), `tokio-tungstenite`, `futures-util`, `sift-api`, `sift-core`.

## File Structure

```
crates/sift-cli/
├─ Cargo.toml                   # + ratatui, crossterm
└─ src/
   ├─ main.rs                   # + Cmd::Tui variant + dispatch
   └─ tui/
      ├─ mod.rs                 # pub async fn run(); terminal lifecycle; event loop
      ├─ state.rs               # AppState, Status, Focus, ScrollMode, WsEvent + unit tests
      ├─ view.rs                # draw(frame, state): header + list + filter bar
      └─ ws.rs                  # async fn run(url, tx): connect + stream + status
```

Responsibilities:

- `tui/state.rs` — pure data + transitions (no I/O, no terminal, no tokio). Fully unit-testable. Owns record buffer cap, filter matching, scroll math, status.
- `tui/view.rs` — rendering only. Takes `&AppState`, draws into a `ratatui::Frame`. No side effects.
- `tui/ws.rs` — WebSocket I/O. Emits `WsEvent`s over an `mpsc::Sender`. No terminal, no ratatui.
- `tui/mod.rs` — wires the three together. Enters raw mode + alt screen, spawns the WS task, runs the event loop, restores terminal on exit (including panic via `Drop` guard).
- `main.rs` — unchanged CLI dispatch, plus one new `Cmd::Tui` variant.

Target size: ~350 lines total across the four new files.

```rust
//! Pure state for the TUI. No I/O, no terminal, no ratatui. Fully testable.

use std::collections::VecDeque;

use sift_api::TailFrame;
use sift_core::Record;

/// Maximum records kept in memory. Older records are dropped.
pub const RECORD_CAP: usize = 500;

/// Events the TUI consumes from the WebSocket task.
#[derive(Debug, Clone)]
pub enum WsEvent {
    Status(Status),
    Frame(TailFrame),
    /// WebSocket terminated; the TUI shows "disconnected" and stops receiving.
    Disconnected,
}

/// Connection status shown in the header pill.
#[derive(Debug, Clone, Copy, Eq, PartialEq)]
pub enum Status {
    Connecting,
    Connected,
    Disconnected,
}

impl Status {
    #[must_use]
    pub fn label(self) -> &'static str {
        match self {
            Self::Connecting => "connecting",
            Self::Connected => "connected",
            Self::Disconnected => "disconnected",
        }
    }
}

/// Where keyboard input goes.
#[derive(Debug, Clone, Copy, Eq, PartialEq)]
pub enum Focus {
    /// Keys affect the record list (scroll, quit).
    List,
    /// Keys edit the filter string.
    Filter,
}

/// Whether the list is pinned to newest records or to a fixed offset.
#[derive(Debug, Clone, Copy, Eq, PartialEq)]
pub enum ScrollMode {
    /// Always show the newest records at the bottom.
    Follow,
    /// Pinned: `offset` = index of the top visible record in the *filtered* view.
    Locked { offset: usize },
}

#[derive(Debug)]
pub struct AppState {
    records: VecDeque<Record>,
    pub status: Status,
    pub focus: Focus,
    pub filter: String,
    pub scroll: ScrollMode,
    pub should_quit: bool,
}

impl Default for AppState {
    fn default() -> Self {
        Self::new()
    }
}

impl AppState {
    #[must_use]
    pub fn new() -> Self {
        Self {
            records: VecDeque::with_capacity(RECORD_CAP),
            status: Status::Connecting,
            focus: Focus::List,
            filter: String::new(),
            scroll: ScrollMode::Follow,
            should_quit: false,
        }
    }

    /// Number of records held in memory (unfiltered).
    #[must_use]
    pub fn record_count(&self) -> usize {
        self.records.len()
    }

    pub fn push_record(&mut self, record: Record) {
        if self.records.len() == RECORD_CAP {
            self.records.pop_front();
        }
        self.records.push_back(record);
    }

    pub fn apply_ws_event(&mut self, evt: WsEvent) {
        match evt {
            WsEvent::Status(s) => self.status = s,
            WsEvent::Frame(TailFrame::Record(r)) => self.push_record(r),
            WsEvent::Frame(_) => {}
            WsEvent::Disconnected => self.status = Status::Disconnected,
        }
    }

    /// Returns the filtered record slice as owned references.
    /// Ordering matches insertion order (oldest first).
    #[must_use]
    pub fn filtered(&self) -> Vec<&Record> {
        if self.filter.is_empty() {
            return self.records.iter().collect();
        }
        let needle = &self.filter;
        self.records.iter().filter(|r| r.body.contains(needle)).collect()
    }

    pub fn set_filter(&mut self, s: String) {
        self.filter = s;
        // Editing the filter resets to follow-mode so the newest hits stay
        // visible. Without this, scroll offsets become stale silently.
        self.scroll = ScrollMode::Follow;
    }

    pub fn focus_filter(&mut self) {
        self.focus = Focus::Filter;
    }

    pub fn unfocus_filter(&mut self) {
        self.focus = Focus::List;
    }

    pub fn quit(&mut self) {
        self.should_quit = true;
    }

    /// Scroll up by `n` rows. Enters `Locked` mode if currently following.
    pub fn scroll_up(&mut self, n: usize) {
        let filtered_len = self.filtered().len();
        let current = match self.scroll {
            ScrollMode::Follow => filtered_len.saturating_sub(1),
            ScrollMode::Locked { offset } => offset,
        };
        self.scroll = ScrollMode::Locked { offset: current.saturating_sub(n) };
    }

    /// Scroll down by `n` rows. Re-enters `Follow` when we reach the tail.
    pub fn scroll_down(&mut self, n: usize) {
        let filtered_len = self.filtered().len();
        let current = match self.scroll {
            ScrollMode::Follow => return, // already at tail
            ScrollMode::Locked { offset } => offset,
        };
        let new_offset = current.saturating_add(n);
        if new_offset + 1 >= filtered_len {
            self.scroll = ScrollMode::Follow;
        } else {
            self.scroll = ScrollMode::Locked { offset: new_offset };
        }
    }

    /// Return to follow mode (e.g. End key).
    pub fn follow(&mut self) {
        self.scroll = ScrollMode::Follow;
    }
}
```

```rust
//! `sift tui` — Ratatui-based terminal UI for live-tail with filter.

mod state;

use std::io::{self, Stdout};
use std::time::Duration;

use anyhow::Context;
use crossterm::event::{
    DisableBracketedPaste, EnableBracketedPaste, Event, EventStream, KeyCode, KeyEvent,
    KeyEventKind, KeyModifiers,
};
use crossterm::execute;
use crossterm::terminal::{
    disable_raw_mode, enable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen,
};
use futures_util::StreamExt;
use ratatui::backend::CrosstermBackend;
use ratatui::Terminal;
use tokio::time::{interval, MissedTickBehavior};

use state::{AppState, Focus};

type Tui = Terminal<CrosstermBackend<Stdout>>;

/// Guard that restores the terminal on drop, even across panics.
struct TerminalGuard;

impl TerminalGuard {
    fn install() -> anyhow::Result<Self> {
        enable_raw_mode().context("enable_raw_mode")?;
        execute!(io::stdout(), EnterAlternateScreen, EnableBracketedPaste)
            .context("enter alt screen")?;
        Ok(Self)
    }
}

impl Drop for TerminalGuard {
    fn drop(&mut self) {
        let _ = disable_raw_mode();
        let _ = execute!(io::stdout(), LeaveAlternateScreen, DisableBracketedPaste);
    }
}

pub async fn run(_server: &str) -> anyhow::Result<()> {
    let _guard = TerminalGuard::install()?;
    let backend = CrosstermBackend::new(io::stdout());
    let mut terminal = Terminal::new(backend).context("terminal init")?;
    terminal.clear().context("terminal clear")?;

    let mut state = AppState::new();
    let mut events = EventStream::new();
    let mut redraw = interval(Duration::from_millis(100));
    redraw.set_missed_tick_behavior(MissedTickBehavior::Skip);

    while !state.should_quit {
        terminal.draw(|f| draw_blank(f, &state))?;

        tokio::select! {
            maybe_evt = events.next() => match maybe_evt {
                Some(Ok(Event::Key(k))) if k.kind == KeyEventKind::Press => {
                    handle_key(&mut state, k);
                }
                Some(Ok(_)) => {}
                Some(Err(err)) => return Err(err).context("event stream"),
                None => break,
            },
            _ = redraw.tick() => {}
        }
    }

    Ok(())
}

/// Placeholder draw until Task 4 wires the real view. Renders a blank frame
/// with a one-line hint so the alt-screen isn't eerily empty.
fn draw_blank(f: &mut ratatui::Frame, state: &AppState) {
    use ratatui::widgets::Paragraph;
    let hint = format!(
        "sift tui · status={} · press q or Ctrl+C to quit",
        state.status.label()
    );
    f.render_widget(Paragraph::new(hint), f.area());
}

fn handle_key(state: &mut AppState, key: KeyEvent) {
    // Global quit bindings: Ctrl+C always quits; `q` quits only when the
    // list has focus (filter focus interprets `q` as a literal character).
    if key.modifiers.contains(KeyModifiers::CONTROL) && matches!(key.code, KeyCode::Char('c')) {
        state.quit();
        return;
    }
    match (state.focus, key.code) {
        (Focus::List, KeyCode::Char('q')) => state.quit(),
        _ => {}
    }
}
```

```rust
//! Pure rendering. Takes `&AppState` and writes into a `ratatui::Frame`.

use ratatui::layout::{Constraint, Layout, Rect};
use ratatui::style::{Color, Modifier, Style};
use ratatui::text::{Line, Span};
use ratatui::widgets::{Block, Borders, List, ListItem, Paragraph};
use ratatui::Frame;
use sift_core::{Level, Record};

use super::state::{AppState, Focus, ScrollMode, Status};

pub fn draw(f: &mut Frame, state: &AppState) {
    let [header, body, filter] = Layout::vertical([
        Constraint::Length(1),
        Constraint::Min(1),
        Constraint::Length(1),
    ])
    .areas(f.area());

    render_header(f, header, state);
    render_body(f, body, state);
    render_filter(f, filter, state);
}

fn render_header(f: &mut Frame, area: Rect, state: &AppState) {
    let title = Span::styled(
        "sift · live tail",
        Style::default().fg(Color::Gray).add_modifier(Modifier::BOLD),
    );
    let status_span = Span::styled(
        format!(" [{}] ", state.status.label()),
        status_style(state.status),
    );
    let line = Line::from(vec![title, Span::raw("   "), status_span]);
    f.render_widget(Paragraph::new(line), area);
}

fn status_style(s: Status) -> Style {
    match s {
        Status::Connected => Style::default().fg(Color::Green),
        Status::Disconnected => Style::default().fg(Color::Red),
        Status::Connecting => Style::default().fg(Color::Yellow),
    }
}

fn render_body(f: &mut Frame, area: Rect, state: &AppState) {
    let recs = state.filtered();
    if recs.is_empty() {
        let msg = if state.filter.is_empty() {
            "waiting for records…"
        } else {
            "no records match the filter"
        };
        f.render_widget(
            Paragraph::new(msg).style(Style::default().fg(Color::DarkGray)),
            area,
        );
        return;
    }

    // Inner area available for rows (no borders in M0 to keep it dense).
    let visible = area.height as usize;
    let (start, end) = visible_range(recs.len(), visible, state.scroll);
    let items: Vec<ListItem> = recs[start..end].iter().map(|r| row(r)).collect();
    f.render_widget(List::new(items), area);
}

fn visible_range(total: usize, visible: usize, scroll: ScrollMode) -> (usize, usize) {
    if total == 0 || visible == 0 {
        return (0, 0);
    }
    let v = visible.min(total);
    match scroll {
        ScrollMode::Follow => (total - v, total),
        ScrollMode::Locked { offset } => {
            let start = offset.min(total.saturating_sub(1));
            let end = (start + v).min(total);
            (start, end)
        }
    }
}

fn row(r: &Record) -> ListItem<'_> {
    let ts = r.timestamp.format("%H:%M:%S%.3f").to_string();
    let level_s = level_span(r.level);
    let line = Line::from(vec![
        Span::styled(ts, Style::default().fg(Color::DarkGray)),
        Span::raw(" "),
        Span::styled(format!("{:<10}", r.host), Style::default().fg(Color::Gray)),
        Span::raw(" "),
        Span::styled(format!("{:<8}", r.app), Style::default().fg(Color::Gray)),
        Span::raw(" "),
        level_s,
        Span::raw(" "),
        Span::raw(r.body.clone()),
    ]);
    ListItem::new(line)
}

fn level_span(lvl: Level) -> Span<'static> {
    let (text, color) = match lvl {
        Level::Trace => ("trace", Color::DarkGray),
        Level::Debug => ("debug", Color::Cyan),
        Level::Info => ("info ", Color::Green),
        Level::Warn => ("warn ", Color::Yellow),
        Level::Error => ("error", Color::Red),
        Level::Fatal => ("fatal", Color::Magenta),
    };
    Span::styled(text, Style::default().fg(color))
}

fn render_filter(f: &mut Frame, area: Rect, state: &AppState) {
    let prefix = match state.focus {
        Focus::Filter => "/",
        Focus::List => " ",
    };
    let content = if state.filter.is_empty() && state.focus != Focus::Filter {
        Span::styled(
            "press / to filter, q to quit",
            Style::default().fg(Color::DarkGray),
        )
    } else {
        Span::raw(state.filter.clone())
    };
    let line = Line::from(vec![
        Span::styled(prefix, Style::default().fg(Color::Cyan)),
        Span::raw(" "),
        content,
    ]);
    f.render_widget(
        Paragraph::new(line).block(Block::default().borders(Borders::TOP)),
        area,
    );
}
```

```rust
//! WebSocket tail task for the TUI. Connects, decodes frames, and emits
//! `WsEvent`s into an `mpsc::Sender`. Does not reconnect — on disconnect it
//! emits `WsEvent::Disconnected` and exits.

use futures_util::StreamExt;
use sift_api::TailFrame;
use tokio::sync::mpsc;
use tokio_tungstenite::connect_async;
use tokio_tungstenite::tungstenite::Message;

use super::state::{Status, WsEvent};

/// Connect to `ws_url` and forward frames into `tx` until the socket closes
/// or an error occurs. Always ends by sending `WsEvent::Disconnected` so the
/// UI reflects the terminal state (unless the channel is already closed).
pub async fn run(ws_url: String, tx: mpsc::Sender<WsEvent>) {
    let _ = tx.send(WsEvent::Status(Status::Connecting)).await;
    let (mut ws, _) = match connect_async(&ws_url).await {
        Ok(x) => x,
        Err(_) => {
            let _ = tx.send(WsEvent::Disconnected).await;
            return;
        }
    };
    let _ = tx.send(WsEvent::Status(Status::Connected)).await;

    while let Some(msg) = ws.next().await {
        let Ok(msg) = msg else { break };
        let text = match msg {
            Message::Text(t) => t,
            Message::Close(_) => break,
            Message::Binary(_) | Message::Ping(_) | Message::Pong(_) | Message::Frame(_) => {
                continue;
            }
        };
        let Ok(frame) = serde_json::from_str::<TailFrame>(&text) else {
            continue;
        };
        if tx.send(WsEvent::Frame(frame)).await.is_err() {
            return; // UI dropped; stop cleanly.
        }
    }

    let _ = tx.send(WsEvent::Disconnected).await;
}

/// Rewrite an HTTP base URL to a WebSocket base URL and append `/v1/tail`.
#[must_use]
pub fn tail_url(server: &str) -> String {
    let base = server
        .replace("http://", "ws://")
        .replace("https://", "wss://");
    format!("{}/v1/tail", base.trim_end_matches('/'))
}
```

```rust
pub async fn run(server: &str) -> anyhow::Result<()> {
    let _guard = TerminalGuard::install()?;
    let backend = CrosstermBackend::new(io::stdout());
    let mut terminal = Terminal::new(backend).context("terminal init")?;
    terminal.clear().context("terminal clear")?;

    let (ws_tx, mut ws_rx) = tokio::sync::mpsc::channel::<state::WsEvent>(256);
    let ws_handle = tokio::spawn(ws::run(ws::tail_url(server), ws_tx));

    let mut state = AppState::new();
    let mut events = EventStream::new();
    let mut redraw = interval(Duration::from_millis(100));
    redraw.set_missed_tick_behavior(MissedTickBehavior::Skip);

    while !state.should_quit {
        terminal.draw(|f| view::draw(f, &state))?;

        tokio::select! {
            maybe_evt = events.next() => match maybe_evt {
                Some(Ok(Event::Key(k))) if k.kind == KeyEventKind::Press => {
                    handle_key(&mut state, k);
                }
                Some(Ok(_)) => {}
                Some(Err(err)) => return Err(err).context("event stream"),
                None => break,
            },
            Some(evt) = ws_rx.recv() => {
                state.apply_ws_event(evt);
            },
            _ = redraw.tick() => {}
        }
    }

    ws_handle.abort();
    let _ = ws_handle.await;
    Ok(())
}
```

```rust
fn handle_key(state: &mut AppState, key: KeyEvent) {
    // Ctrl+C always quits.
    if key.modifiers.contains(KeyModifiers::CONTROL) && matches!(key.code, KeyCode::Char('c')) {
        state.quit();
        return;
    }

    match state.focus {
        Focus::List => handle_list_key(state, key),
        Focus::Filter => handle_filter_key(state, key),
    }
}

fn handle_list_key(state: &mut AppState, key: KeyEvent) {
    match key.code {
        KeyCode::Char('q') => state.quit(),
        KeyCode::Char('/') => state.focus_filter(),
        KeyCode::Up => state.scroll_up(1),
        KeyCode::Down => state.scroll_down(1),
        KeyCode::PageUp => state.scroll_up(10),
        KeyCode::PageDown => state.scroll_down(10),
        KeyCode::Home => state.scroll_up(usize::MAX / 2),
        KeyCode::End => state.follow(),
        _ => {}
    }
}

fn handle_filter_key(state: &mut AppState, key: KeyEvent) {
    match key.code {
        KeyCode::Esc => {
            state.unfocus_filter();
        }
        KeyCode::Enter => {
            state.unfocus_filter();
        }
        KeyCode::Backspace => {
            let mut s = state.filter.clone();
            s.pop();
            state.set_filter(s);
        }
        KeyCode::Char(c) => {
            let mut s = state.filter.clone();
            s.push(c);
            state.set_filter(s);
        }
        _ => {}
    }
}
```
